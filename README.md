# Tesla & GameStop Stock Analysis

A hands-on project completed as part of the **IBM Data Science Professional Certificate** on Coursera.

## Overview

This project focuses on extracting, cleaning, and visualizing stock and revenue data for **Tesla (TSLA)** and **GameStop (GME)** using Python.

## Technologies

* Python
* Pandas
* yfinance
* BeautifulSoup
* Web Scraping
* Matplotlib
* Jupyter Notebook

## Key Tasks

* Extract historical stock data using `yfinance`
* Scrape quarterly revenue data
* Clean and prepare financial data
* Visualize stock prices and revenue
